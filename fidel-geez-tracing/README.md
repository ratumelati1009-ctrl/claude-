# ፊደል ግእዝ — ቀዳማይ መደብ (Ge'ez Fidel, First Form) — Tracing Worksheet

A printable kids' handwriting-tracing worksheet for the **Ge'ez fidel (ፊደል)**, teaching the **26 base letters in their traditional order**, each shown in the **first form (ግእዝ / geʼez order)**.

- **By:** Daniel Tesfamariam
- **Contact:** dannyshalomnebiy@gmail.com

## 📥 Download (PDF)

👉 **[Tracing-Fidel-Tigrinya.pdf](Tracing-Fidel-Tigrinya.pdf)** — 26 pages, A4, print-ready.

## What's inside

- **One page per letter**, following the classic fidel teaching order:
  ሀ ለ ሐ መ ሠ ረ ሰ ቀ በ ተ ኀ ነ አ ከ ወ ዐ ዘ የ ደ ገ ጠ ጰ ጸ ፀ ፈ ፐ
- Each letter is shown in its **first form (ግእዝ)**, the order children learn first.
- A **4×5 grid of traceable (outlined) letters** for handwriting practice.
- Each page shows the **letter name** (e.g. ሆይ, ላዊ, ማይ …) and a **romanization** (hä, lä, mä …).
- A **star "count & color" motif** on every page for a fun counting activity.
- A friendly rotating color theme per page.
