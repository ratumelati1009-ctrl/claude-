# Coloring Books

Two complete, print-ready coloring books. Each is 100% original vector line art
generated by a small zero-dependency Python toolkit, exported to print-ready PDF
(8.5 × 11 in) plus per-page SVGs.

## 📕 Cute Animal Friends (`cute-animals/`)
A 42-page **Cute Animals Coloring Book for kids ages 4–10** — puppies, kittens,
pandas, ocean friends, farm animals, and more, all in one consistent adorable
style.

- **`Cute-Animal-Friends-Coloring-Book.pdf`** — single file: cover + full interior (47 pages).
- `interior.pdf` — interior only (46 pages). · `cover.pdf` — cover only.
- `pages/*.svg` — every page as a scalable SVG.
- See `cute-animals/README.md` and `cute-animals/LISTING.md`.

## 📘 Serene Patterns (`serene-patterns/`)
A 42-page **all-ages coloring book** of mandalas, florals, animals, ocean, space,
and zen patterns.

- **`Serene-Patterns-Coloring-Book.pdf`** — single file: cover + full interior (47 pages).
- `interior.pdf` — interior only (46 pages). · `cover.pdf` — cover only.
- `pages/*.svg` — every page as a scalable SVG.
- See `serene-patterns/README.md` and `serene-patterns/LISTING.md`.

## Regenerate any book
```bash
cd cute-animals   # or: cd serene-patterns
python3 build_book.py
```
Pure Python 3, no external packages (works offline).

## Print / self-publish
Both are 8.5 × 11 in, portrait, black line art on white — ready for print-on-demand
(Amazon KDP, Lulu, IngramSpark) or home printing. Each book's `LISTING.md` has
ready-to-paste sales copy and a KDP publishing checklist.
