## KDP / print-on-demand publishing checklist
- [ ] Confirm final **trim size** (this build: 8.5 × 11 in).
- [ ] For a single-sided feel on a double-sided printer, add a blank page after
      each design.
- [ ] **Bleed:** current build keeps art inside a frame with safe margins (no
      bleed), which is fine for most POD. Add ~0.125 in bleed only if you want
      art running to the edge.
- [ ] **Cover:** `cover.pdf` is a front-only design. For a KDP paperback,
      generate a full wrap (back + spine + front) using KDP's cover calculator
      once you know the page count and paper type.
- [ ] Add an ISBN (KDP can assign a free one).
- [ ] Upload `interior.pdf`, run KDP's previewer, order a proof copy.
