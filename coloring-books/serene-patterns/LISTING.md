## KDP / print-on-demand publishing checklist
- [ ] Confirm final **trim size** (this build: 8.5 × 11 in).
- [ ] Interior: single-sided is achieved by keeping design pages as-is; if your
      printer prints double-sided, add a blank page between designs.
- [ ] **Bleed:** if any art should run to the edge, rebuild with a bleed margin
      (add ~0.125 in on each side). Current build uses a safe inner margin and
      no bleed (art sits inside a frame), which is fine for most POD.
- [ ] **Cover:** `cover.pdf` is a front-only 8.5 × 11 design. For a KDP paperback
      you'll generate a full wrap (back + spine + front); spine width depends on
      page count and paper — use KDP's cover template calculator.
- [ ] Add an ISBN (KDP can assign a free one).
- [ ] Upload `interior.pdf`, run KDP's previewer, order a proof copy.
