# ምስሊ ቁጽሪ (ትግርኛ) — Tracing Numbers, Tigrinya / Ge'ez Edition

A printable kids' number-tracing worksheet in **Tigrinya using Ge'ez numerals (፩–፱)**, adapted from the "Tracing Numbers – Count the Cats" style.

- **By:** Daniel Tesfamariam
- **Contact:** dannyshalomnebiy@gmail.com

## 📥 Download (PDF)

👉 **[Tracing-Numbers-Tigrinya.pdf](Tracing-Numbers-Tigrinya.pdf)** — 9 pages, A4, print-ready.

## What's inside

- One page per number, **1 → 9**, each showing the **Ge'ez numeral** (፩ ፪ ፫ ፬ ፭ ፮ ፯ ፰ ፱).
- A **4×5 grid of traceable (outlined) numerals** for handwriting practice.
- The matching **number of cats to count** on each page (1 cat on page 1, 6 cats on page 6, etc.).
- Bilingual learning aid: each page also shows the Western digit and the Tigrinya number word
  (ሓደ, ክልተ, ሰለስተ, ኣርባዕተ, ሓሙሽተ, ሽዱሽተ, ሸውዓተ, ሸሞንተ, ትሽዓተ).
- A different friendly color theme per page.

## Rebuilding

```bash

```
